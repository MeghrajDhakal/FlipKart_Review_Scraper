FLIPKART REVIEW API - UPGRADE REPORT & PERFORMANCE BENCHMARK

1. OVERVIEW & DIAGNOSIS OF OUTDATED CODE
--------------------------------------------------------------------------------
The codebase was an API and Scrapy crawler built to scrape product reviews and 
ratings from Flipkart. Prior to this update, the scraper was completely broken, 
producing empty output (`[][ ]`) and `None` for every single field.

The root causes identified were:
  a) Scrapy robots.txt Enforcement (ROBOTSTXT_OBEY = True):
     Flipkart's robots.txt disallows `*/product-reviews/*` and `/reviews/*`.
     Scrapy dropped review page requests immediately with 
     "Forbidden by robots.txt", never fetching any review data.

  b) Fragile, Outdated Deep XPaths:
     The scraper relied on hard-coded index-based XPaths like:
       `//html[1]/body/div/div/div[3]/div[1]/div[1]/div[2]/div[13]/div/div/span/text()`
     Flipkart restructured its entire frontend using React Native for Web with 
     atomic CSS classes (`css-g5y9jx`, etc.). Every old XPath failed, resulting 
     in 0 reviews scraped and all summary values returning `None`.

  c) Missing User-Agent & Browser Headers:
     `USER_AGENT` was commented out in settings, sending Scrapy's default bot 
     agent (`Scrapy/2.13.3 (+https://scrapy.org)`). Flipkart responded with HTTP 
     429 (Too Many Requests) or HTTP 500 error pages ("Something went wrong! E002").

  d) Product-to-Review Navigation Broken:
     The link selector `//a/div/span/../../@href` failed to detect "All Reviews" 
     links on modern Flipkart product pages, causing the spider to treat product 
     pages as review pages and fail.

  e) Concurrency & Stability Bugs in `app.py`:
     - Global File Collision: Used a fixed filename `output.json`. Simultaneous 
       requests would overwrite or corrupt each other's output.
     - UnboundLocalError: If `page` or `url` was missing from query args, Flask 
       crashed with an unhandled Python exception.
     - Content-Type: Returned raw file text with default `text/html` instead of 
       `application/json`.
     - Scrapy `-o` Flag: In newer Scrapy versions, `-o` appends rather than 
       overwrites, leading to malformed JSON (`[...][...]`).


2. WHAT WAS CHANGED (DETAILED FILE-BY-FILE BREAKDOWN)
--------------------------------------------------------------------------------

A. `reviewapi/settings.py`:
   - Set `ROBOTSTXT_OBEY = False`: Allows requests to `/product-reviews/` routes.
   - Added realistic desktop browser `USER_AGENT` (Chrome 128 on Windows).
   - Configured `DEFAULT_REQUEST_HEADERS` (`sec-ch-ua`, `Accept-Language`, 
     `upgrade-insecure-requests`, etc.) to mimic real browser traffic.
   - Configured polite `DOWNLOAD_DELAY = 1.0` and `CONCURRENT_REQUESTS = 4` to 
     prevent rate limiting.
   - Enabled `COOKIES_ENABLED = True` for Flipkart session tracking.
   - Configured automatic retries (`RETRY_ENABLED = True`, `RETRY_TIMES = 3`, 
     `RETRY_HTTP_CODES = [500, 502, 503, 504, 522, 524, 408, 429]`).
   - Set `FEED_EXPORT_ENCODING = 'utf-8'`.

B. `reviewapi/spiders/reviewSpider.py`:
   - Shifted extraction to Flipkart's hydration state (`window.__INITIAL_STATE__` /
     `<script id="is_script">`). This payload contains complete, typed, server-
     rendered data structures (`UgcRatingValue`, `ProductReviewValue`) that do 
     not rely on fragile HTML tags or hashed CSS class names.
   - Automatic URL Routing & Multi-Page Pagination:
     * Product URLs (`/p/`): Scrapes product price first, automatically converts 
       path to `/product-reviews/`, applies requested `page` query parameter, 
       and follows through to scrape reviews.
     * Direct Review URLs (`/product-reviews/`): Immediately parses reviews for 
       the specified page.
     * All-Reviews Pagination (`page=all` or `max_pages=N`): Automatically crawls 
       page 1, page 2, ... up to the last page using Flipkart's `hasMorePages` 
       flag and total review count, yielding summary rating stats once and all 
       reviews continuously.
   - Accurate Field Extraction:
     * Product Price: Extracted from `seoData.schema`, `fdpEventTracking`, or 
       JSON-LD.
     * Summary Metrics: Extracted `review_title`, `avg_rating`, `total_ratings`, 
       `total_reviews`, `total_pages`, and exact 5/4/3/2/1 star distribution counts.
     * Reviews: Extracted `review_score`, `review_title`, `review_content`, 
       `reviewer_name`, `reviewer_location` (city, state), `reviewer_date`, 
       `permalink`, `upvote`, and `downvote`.
   - Modern Scrapy 2.13+ Compatibility:
     * Implemented `async def start(self)` alongside `start_requests()` to eliminate 
       deprecation warnings.
     * Added DOM/Regex fallback parser in case the script tag format changes.

C. `reviewapi/items.py`:
   - Added typed Scrapy items (`ProductPriceItem`, `ReviewSummaryItem`, `ReviewItem`) 
     for formal schema definitions and validation.

D. `app.py`:
   - Concurrency Safety: Replaced static `output.json` with isolated temporary 
     files (`tempfile.NamedTemporaryFile`) cleaned up in a `finally` block.
   - Query Parameter Validation:
     * Missing `url`: Returns clean `400 Bad Request` with helpful error JSON.
     * `page`: Defaults to `1` safely and handles non-integer input without crashing.
   - Scrapy Flag `-O`: Uses `-O` (overwrite) to ensure clean, valid JSON output.
   - Proper REST Responses:
     * Uses `flask.jsonify()` so responses always return `application/json`.
     * Added home endpoint (`/`) with API metadata, usage instructions, and endpoints.
     * Added health check endpoint (`/health`).
     * Added timeouts and error handling (`502` on scraper failure, `504` on timeout).

E. `requirements.txt`:
   - Modernized package requirements (`Flask>=3.0.0`, `gunicorn>=21.0.0`, `scrapy>=2.11.0`).

F. `.gitignore`:
   - Created `.gitignore` ignoring Python caches, temporary test files, JSON feeds, 
     and editor settings.

G. Unit & Integration Test Suite (`tests/`):
   - Created `tests/test_spider.py` testing URL building, state extraction, and item parsing.
   - Created `tests/test_api.py` testing Flask endpoints and input validation.
